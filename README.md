# Telegram-секретарь (русский + узбекский)

Бот-секретарь: отвечает людям вместо вас, передаёт вам сообщения, проверяет присланные файлы на вирусы
и управляется кнопками. Это обычный бот из @BotFather — **Telegram Premium боту не нужен**, платные функции
Telegram он не использует.

## Что умеет

- **Автоответы** на русском и узбекском (язык определяется по тексту собеседника), пока вы «не в сети».
- **Триггеры** по ключевым словам (цена, адрес, график, «срочно»…) — `config.json`.
- **Передаёт вам сообщения**: каждое сообщение, пришедшее в ваше отсутствие, бот присылает вам в личку
  (кто написал, текст, что ответил) с кнопкой «Не отвечать этому чату».
- **Проверка файлов в VirusTotal**: присланный файл проверяется, вердикт приходит вам (см. ниже).
- **Меню из кнопок**: `/menu` — включить/выключить режимы, поменять тексты, игнор-лист, состояние.
- **Не перебивает**: если вы сами написали в чате, бот молчит в нём 30 минут.
- «Не в сети» включается кнопкой, по расписанию и (по желанию) если вы долго молчите.

## Два способа общения с людьми

1. **Подключение к вашему аккаунту (Business).** Бот отвечает прямо в ваших личных чатах от вашего имени.
   Настройка: @BotFather → ваш бот → **Bot Settings → Business Mode** → включить; затем в Telegram
   **Настройки → Telegram Business → Чат-боты** → укажите бота и включите право «Отвечать на сообщения».
2. **Прямой режим.** Люди пишут **самому боту** (дайте им ссылку `t.me/имя_бота`). Бот отвечает как
   «приёмная» (всегда, а не только когда вы не в сети), пересылает вам сообщение, а вы отвечаете клиенту
   через **Reply** на это уведомление. Работает без подключения Business — если этого раздела нет в вашем
   приложении, пользуйтесь прямым режимом.

Оба способа работают одновременно.

## Первый запуск

1. В @BotFather: `/newbot` → получите **токен**.
2. Укажите, кто владелец: переменная **`OWNER_USERNAME`** (ваш @username без `@`) или `OWNER_ID`
   (числовой id). Для Business-подключения это необязательно — владелец определяется сам.
3. Запустите бота (ниже), откройте его в Telegram и отправьте `/start` — появится меню.

### Запуск на своём компьютере

Нужен только Python 3.9+ (пакеты ставить не надо).

```
export BOT_TOKEN=токен_от_BotFather
export OWNER_USERNAME=ваш_username
python secretary.py
```

В Windows PowerShell: `$env:BOT_TOKEN="токен"`. Остановить — `Ctrl+C`. На сервере (Render) — см. **RENDER.md**.

## Меню (`/menu`)

| Кнопка | Что делает |
|---|---|
| Не в сети: ВКЛ/выкл | секретарь отвечает вместо вас |
| Триггеры / Пересылка | включить или выключить |
| Проверка файлов | включить или выключить (нужен `VT_API_KEY`) |
| ✏️ Тексты | посмотреть и изменить автоответ на RU и UZ (бот попросит прислать новый текст) |
| 🚫 Игнор | чаты, где бот молчит; можно вернуть кнопкой |
| 📊 Состояние / 🔄 Сбросить паузы / ♻️ Перечитать config | служебное |

Есть и текстовые команды: `/on`, `/off`, `/status`, `/triggers on|off`, `/notify on|off`, `/scan on|off`,
`/text ru|uz <текст>`, `/ignore <id>`, `/unignore <id>`, `/reset`, `/reload`. Команды и кнопки принимаются
только от владельца.

## Проверка файлов в VirusTotal

1. Зарегистрируйтесь на virustotal.com → профиль → **API key** → вставьте в переменную **`VT_API_KEY`**.
2. Как это работает:
   - Файл, присланный клиентом (в Business-чате или боту напрямую), бот скачивает из Telegram, считает
     его отпечаток (SHA-256) и **спрашивает VirusTotal только по отпечатку** — сам файл при этом никуда не уходит.
   - Если VirusTotal файл уже знает — вам сразу приходит вердикт: ✅ чисто / ⚠️ подозрительно / 🚫 вредоносный,
     количество срабатываний и ссылка на отчёт.
   - Если файл неизвестен — бот **спрашивает вас кнопкой**, загружать ли его на проверку. Загруженные файлы
     становятся доступны сервису и, возможно, другим его пользователям, поэтому по умолчанию решаете вы.
     `VT_AUTO_UPLOAD=1` включает загрузку без вопроса.
   - Файл, который **вы сами** отправили боту в личку, проверяется и загружается сразу.
   - Проверка идёт, даже если вы онлайн и автоответ выключен.
3. Ограничения:
   - Проверяются файлы, отправленные «как файл» (документы), до 20 МБ (лимит Bot API). Фото, видео,
     голосовые не проверяются.
   - Бесплатный ключ: 4 запроса в минуту, 500 в сутки, только для некоммерческого использования. Бот сам
     выдерживает паузы, поэтому проверки идут по очереди; суточный лимит бота — `VT_DAILY_LIMIT` (по умолчанию 100 проверок).
   - Вердикт — подсказка, а не гарантия: «чисто» не значит «безопасно», особенно для новых файлов.

## Триггеры и тексты (config.json)

```json
{
  "name": "price",
  "cooldown_minutes": 30,
  "only_when_away": true,
  "keywords": { "ru": ["цена$", "сколько стоит"], "uz": ["narx", "qancha turadi", "нарх"] },
  "replies":  { "ru": "Отвечу позже…", "uz": "Keyinroq javob beraman…" }
}
```

- Слово совпадает **с начала слова**: `narx` найдёт «narxi», «narxlar». `$` в конце — только целое слово
  (`цена$` не сработает на «центр»).
- Можно писать фразы, апострофы `o'` / `oʻ` / `o‘` равнозначны, регистр и «ё/е» не важны,
  узбекские слова — и латиницей, и кириллицей.
- Срабатывает **первый** подходящий триггер сверху вниз.
- `only_when_away: false` — отвечает всегда (как FAQ).
- `{name}` в тексте заменяется на имя собеседника. Ответ на узбекском — латиницей.

**Тексты в `config.json` — шаблоны.** Подставьте реальные цены, адрес и график: бот отправляет ровно то,
что там написано.

## Настройки (переменные окружения)

| Переменная | По умолчанию | Смысл |
|---|---|---|
| `BOT_TOKEN` | — | **обязательно**, токен от @BotFather |
| `OWNER_USERNAME` / `OWNER_ID` | пусто | кто владелец (меню, пересылка, прямой режим) |
| `VT_API_KEY` | пусто | ключ VirusTotal; без него проверка файлов выключена |
| `VT_AUTO_UPLOAD` | `0` | `1` — загружать неизвестные файлы в VirusTotal без вопроса |
| `VT_DAILY_LIMIT` | `100` | проверок файлов в сутки |
| `MODE` | `polling` | `polling` или `webhook` (Render Web Service) |
| `WEBHOOK_URL` | — | для `webhook`: адрес сервиса `https://….onrender.com` |
| `TZ_NAME` | `Asia/Tashkent` | часовой пояс |
| `AWAY_FROM`, `AWAY_TO` | пусто | расписание «не в сети», `ЧЧ:ММ` (можно через полночь) |
| `IDLE_MINUTES` | `0` | `>0`: считать вас «не в сети», если вы не писали дольше N минут (Business) |
| `HANDOFF_MINUTES` | `30` | сколько молчать в чате после вашего ответа (Business) |
| `COOLDOWN_HOURS` | `6` | как часто отвечать «я не в сети» одному человеку |
| `REPLY_DELAY_MIN/MAX` | `1` / `3` | пауза с «печатает…» перед ответом, сек (`0` — без паузы) |
| `STATE_FILE`, `CONFIG_PATH` | рядом со скриптом | пути к файлам |
| `LOG_LEVEL` | `INFO` | уровень логов |

## Безопасность

- Токен бота и ключ VirusTotal — как пароли. Не публикуйте их и не коммитьте в GitHub (`.gitignore` исключает
  `.env`, `state.json`). Если токен попал в чат или репозиторий — перевыпустите: @BotFather → `/revoke`.
- Скачанные файлы бот не сохраняет и не открывает: они живут в памяти только на время проверки.
- Тексты сообщений собеседников не пишутся в логи и в файл состояния; вам они приходят только в личку от бота.
