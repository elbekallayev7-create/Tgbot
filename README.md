# Автоответчик для Telegram (русский + узбекский)

Отвечает на личные сообщения от вашего аккаунта, когда вы не в сети. Понимает ключевые слова
(триггеры) на русском и узбекском и отвечает на том языке, на котором написал собеседник.

## Файлы

| Файл | Что это |
|---|---|
| `autoreply.py` | сам бот |
| `triggers.py` | триггеры и определение языка (без Telegram) |
| `config.json` | **ваши тексты и триггеры — редактируйте его** |
| `make_session.py` | одноразовый вход для запуска на сервере |
| `test_*.py` | тесты (`pip install pytest`, затем `python -m pytest -q`) |

## Быстрый старт

1. На https://my.telegram.org → *API development tools* получите `api_id` и `api_hash`.
2. Нужен Python 3.9+. Установите зависимости: `pip install -r requirements.txt`
3. Запустите:

   ```
   export TG_API_ID=12345678
   export TG_API_HASH=ваш_api_hash
   python autoreply.py
   ```

   В Windows PowerShell: `$env:TG_API_ID="12345678"`. При первом запуске введите телефон и код.

## Как решается, что вы «не в сети»

* вручную: напишите себе в «Избранное» `/away on` или `/away off`;
* по расписанию: `AWAY_FROM=23:00` и `AWAY_TO=08:00` (можно через полночь; часовой пояс —
  `TZ_NAME`, по умолчанию `Asia/Tashkent`).

Бот включён, если включён хотя бы один из способов. Telegram не сообщает программе ваш статус
«онлайн», поэтому автоматически определить его нельзя.

## Триггеры (config.json)

```json
{
  "name": "price",
  "cooldown_minutes": 30,
  "only_when_away": true,
  "keywords": { "ru": ["цена$", "сколько стоит"], "uz": ["narx", "qancha turadi", "нарх"] },
  "replies":  { "ru": "Отвечу позже…", "uz": "Keyinroq javob beraman…" }
}
```

* Ключевое слово совпадает **с начала слова**: `narx` найдёт «narxi», «narxlar»; `адрес` — «адреса».
* `$` в конце — слово целиком: `цена$` найдёт «цена», но не «центр».
* Можно писать фразы из нескольких слов, любые апострофы (`o'`, `oʻ`, `o‘`) считаются одинаковыми,
  регистр и «ё/е» не важны. Узбекские слова можно писать и латиницей, и кириллицей.
* Срабатывает **первый** подходящий триггер сверху вниз — порядок задаёт приоритет.
* `only_when_away: false` — триггер отвечает всегда, даже когда вы онлайн (как FAQ-бот).
* `{name}` в тексте заменяется на имя собеседника.
* Языки: `ru` и `uz` (ответ на узбекском — латиницей).
* Язык ответа: по ключевому слову, которое сработало, а для обычного автоответа — по тексту
  сообщения (кириллица → русский, латиница → узбекский; настраивается `latin_lang`). Для стикеров
  и фото берётся язык предыдущего сообщения этого человека.

**Важно:** тексты в `config.json` — шаблоны. Подставьте реальные цены, адрес и график, когда будете готовы:
бот отвечает ровно то, что вы там написали.

После правки `config.json` отправьте себе `/away reload` — перезапуск не нужен.

## Команды (писать в «Избранное»)

| Команда | Действие |
|---|---|
| `/away on` / `/away off` | включить / выключить вручную |
| `/away status` | показать состояние |
| `/away triggers on` / `off` | включить / выключить триггеры |
| `/away text ru Я в отпуске` | свой текст автоответа (`uz` — для узбекского; `reset` — вернуть из конфига) |
| `/away ignore @username` / `unignore` | не отвечать конкретному человеку |
| `/away reset` | сбросить паузы между ответами |
| `/away reload` | перечитать `config.json` |

## Настройки (переменные окружения, всё необязательное)

| Переменная | По умолчанию | Смысл |
|---|---|---|
| `AWAY_FROM`, `AWAY_TO` | пусто | расписание «не в сети», `ЧЧ:ММ` |
| `TZ_NAME` | `Asia/Tashkent` | часовой пояс |
| `COOLDOWN_HOURS` | `6` | как часто отвечать «я не в сети» одному человеку |
| `REPLY_DELAY_MIN/MAX` | `1` / `3` | пауза с «печатает…» перед ответом, секунды (`0` — без паузы) |
| `CONFIG_PATH`, `STATE_FILE` | рядом со скриптом | пути к конфигу и файлу состояния |
| `LOG_LEVEL` | `INFO` | уровень логов |

## Безопасность

* Строка сессии и файл `*.session` дают полный доступ к вашему аккаунту — не публикуйте их.
* Бот отвечает только в личных чатах, не отвечает ботам и служебным уведомлениям Telegram.
* Тексты сообщений собеседников не записываются в логи и в состояние.
* Если у вас Telegram Premium, в настройках Business есть встроенный автоответчик.
