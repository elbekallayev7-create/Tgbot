# Telegram-секретарь (русский + узбекский)

Бот-секретарь в том смысле, как это устроено в Telegram: обычный бот из @BotFather, который вы
подключаете к своему аккаунту в **Telegram Business → Чат-боты** (режим секретаря). Он видит ваши личные
чаты и отвечает в них **от вашего имени**. Входить в аккаунт через api_id не нужно — нужен только токен бота.

## Что умеет

- Пока вы «не в сети» — отвечает на русском или узбекском (язык определяется по тексту собеседника).
- **Триггеры** по ключевым словам (цена, адрес, график, «срочно»…) — `config.json`.
- **Передаёт вам сообщения**: каждое сообщение, пришедшее в ваше отсутствие, бот присылает вам в личку
  (кто написал, текст, что ответил). Ничего не теряется.
- **Не перебивает**: если вы сами написали в чате, бот молчит в нём 30 минут (`HANDOFF_MINUTES`).
- «Не в сети» включается вручную (`/on`), по расписанию и (по желанию) если вы молчите дольше N минут.
- Не отвечает в группах, каналах, другим ботам; отвечает не чаще раза в 6 часов одному человеку.

## Настройка в Telegram (один раз)

1. В @BotFather: `/newbot` → получите **токен**.
2. @BotFather → `/mybots` → ваш бот → **Bot Settings → Business Mode** → включить.
3. В Telegram: **Настройки → Telegram Business → Чат-боты** → укажите имя бота, выберите чаты и
   включите право **«Отвечать на сообщения»**. Если раздела нет в вашем приложении, он может требовать
   Telegram Premium — проверьте в настройках.
4. Откройте бота и нажмите **Start**: так он сможет присылать вам уведомления.

Бот может отвечать только в чатах, где была активность за последние 24 часа (ограничение Telegram) — для
ответа на свежее входящее сообщение это не мешает.

## Запуск на своём компьютере

Нужен только Python 3.9+ (пакеты ставить не надо).

```
export BOT_TOKEN=токен_от_BotFather
python secretary.py
```

В Windows PowerShell: `$env:BOT_TOKEN="токен"`. Остановить — `Ctrl+C`.
На сервере (Render) — см. **RENDER.md**.

## Команды (писать боту в личку)

| Команда | Действие |
|---|---|
| `/on` / `/off` | включить / выключить «не в сети» вручную |
| `/status` | показать состояние |
| `/triggers on` / `off` | триггеры по ключевым словам |
| `/notify on` / `off` | пересылать мне сообщения, пока меня нет |
| `/text ru Я в отпуске` | свой текст автоответа (`uz` — узбекский; `reset` — вернуть из конфига) |
| `/ignore 123456` / `/unignore 123456` | не отвечать чату (id указан в уведомлении) |
| `/reset` | сбросить паузы между ответами |
| `/reload` | перечитать `config.json` |

Команды принимаются только от владельца (аккаунта, к которому подключён бот).

## Триггеры и тексты (config.json)

```json
{
  "name": "price",
  "cooldown_minutes": 30,
  "only_when_away": true,
  "keywords": { "ru": ["цена$", "сколько стоит"], "uz": ["narx", "qancha turadi", "нарх"] },
  "replies":  { "ru": "Отвечу позже…", "uz": "Keyinroq javob beraman…" }
}
```

- Слово совпадает **с начала слова**: `narx` найдёт «narxi», «narxlar». `$` в конце — только целое слово
  (`цена$` не сработает на «центр»).
- Можно писать фразы, апострофы `o'` / `oʻ` / `o‘` равнозначны, регистр и «ё/е» не важны,
  узбекские слова — и латиницей, и кириллицей.
- Срабатывает **первый** подходящий триггер сверху вниз.
- `only_when_away: false` — отвечает всегда, даже когда вы онлайн (как FAQ).
- `{name}` в тексте заменяется на имя собеседника. Ответ на узбекском — латиницей.

**Тексты в `config.json` — шаблоны.** Подставьте реальные цены, адрес и график: бот отправляет ровно то,
что там написано.

## Настройки (переменные окружения)

| Переменная | По умолчанию | Смысл |
|---|---|---|
| `BOT_TOKEN` | — | **обязательно**, токен от @BotFather |
| `OWNER_ID` | пусто | ваш Telegram id; нужен только если хотите управлять ботом до подключения |
| `MODE` | `polling` | `polling` (бот сам опрашивает Telegram) или `webhook` (Render Web Service) |
| `WEBHOOK_URL` | — | для `webhook`: адрес сервиса `https://….onrender.com` |
| `TZ_NAME` | `Asia/Tashkent` | часовой пояс |
| `AWAY_FROM`, `AWAY_TO` | пусто | расписание «не в сети», `ЧЧ:ММ` (можно через полночь) |
| `IDLE_MINUTES` | `0` | `>0`: считать вас «не в сети», если вы не писали дольше N минут |
| `HANDOFF_MINUTES` | `30` | сколько молчать в чате после вашего ответа |
| `COOLDOWN_HOURS` | `6` | как часто отвечать «я не в сети» одному человеку |
| `REPLY_DELAY_MIN/MAX` | `1` / `3` | пауза с «печатает…» перед ответом, сек (`0` — без паузы) |
| `STATE_FILE`, `CONFIG_PATH` | рядом со скриптом | пути к файлам |
| `LOG_LEVEL` | `INFO` | уровень логов |

## Безопасность

- Токен бота — как пароль. Не публикуйте его и не коммитьте в GitHub (`.gitignore` уже исключает `.env`, `state.json`).
  Если токен попал в чат или репозиторий — перевыпустите его: @BotFather → `/revoke`.
- Тексты сообщений собеседников не пишутся в логи и в файл состояния; вам они приходят только в личку от бота.
